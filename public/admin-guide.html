TDSA · ADMIN HANDBOOK

Admin အသုံးပြုလမ်းညွှန်

ပွဲအသစ်တင်ခြင်း၊ user ပို့ထားသောအချက်အလက်ကို စစ်ဆေးခြင်းနှင့် ဖျက်ခြင်း

၁။ ဝင်ရောက်ခြင်း

Admin စာမျက်နှာတွင် ခွင့်ပြုထားသော Google account ဖြင့် Sign in လုပ်ပါ။ Events နှင့် Community profiles ကို တစ် tab ထဲတွင် ပြောင်းသုံးနိုင်သည်။ Sign out နှိပ်ခြင်း၊ tab ပိတ်ခြင်း သို့မဟုတ် ၁၅ မိနစ် မသုံးခြင်းကြောင့် session ပြီးဆုံးနိုင်သည်။ ဝင်ထားသော session အတွင်း ရေးသား/ဖျက်သည့်အခါ Google login ထပ်မတောင်းပါ။ Delete modal ကို အတည်ပြုရုံဖြင့် ဖျက်သည်။

၂။ User ပို့သည့်ပွဲကို ထုတ်ပြခြင်း

  1. Events → Submission inbox ကိုကြည့်ပါ။ အသစ်ပို့လာသော submission များ အလိုအလျောက်ပေါ်သည်။
  2. Review & publish event ကိုနှိပ်ပါ။ Editor ထဲသို့ draft အဖြစ်ယူသည်။ ဒီခလုတ်နှိပ်ရုံဖြင့် public မဖြစ်သေးပါ။
  3. ပွဲအမည်၊ ကျောင်းအမည်၊ လိပ်စာ၊ city၊ state၊ ရက်စွဲနှင့် poster ကိုစစ်ပါ။ State သည် NC, TX စသည့် စာလုံးနှစ်လုံးဖြစ်ရမည်။ Kitty Hawk သည် NC ဖြစ်သည်။
  4. Publish နှိပ်ပါ။ အောင်မြင်ကြောင်းစာပေါ်ပြီး form ပိတ်သွားသည်။ User Events နှင့် ချိတ်ထားသော submission status အလိုအလျောက်ပြောင်းသည်။

၃။ ခလုတ်တစ်ခုချင်း၏ အလုပ်

Publish
အချက်အလက်မှန်ကန်ပါက အများပြည်သူကြည့်နိုင်အောင် သိမ်းသည်။
Save event
Publication dropdown ရွေးထားသည့်အတိုင်း သိမ်းသည်။ Draft ဆိုလျှင် admin သာမြင်ရပြီး Published ဆိုလျှင် public ဖြစ်သည်။ Archived ဆိုလျှင် public မှဖယ်ထားသည်။
Mark reviewed
ပို့ထားသည့်တောင်းဆိုချက်ကို စစ်ဆေးပြီးကြောင်းသာ မှတ်သားသည်။ Event ကို မထုတ်ပြပါ။ ပြင်ဆင်ချက် သို့မဟုတ် သီးခြားဖြေရှင်းပြီးသော တောင်းဆိုချက်များအတွက် သုံးပါ။
Delete private submission
Inbox ထဲက user ပို့ထားသောစာနှင့် photo ကိုဖျက်သည်။ တင်ပြီးသား event ကို မဖျက်ပါ။
Edit / Publish
အောက်က event စာရင်းမှ ရှိပြီးသား record ကို ပြင်ရန် editor ပြန်ဖွင့်သည်။
Delete event
ပွဲနှင့်ပွဲ photo ကို အပြီးဖျက်သည်။ Modal တွင် Cancel ဖြင့်ရပ်နိုင်သည်။ ဖျက်ပြီးနောက် public စာရင်းမှ အလိုအလျောက်ပျောက်သည်။ မပျက်စီးလိုပါက Archived ရွေးပြီး Save လုပ်ပါ။

၄။ Link existing event ကို ဘယ်အချိန်သုံးမလဲ

အရင် version ဖြင့်တင်ထားသောပွဲတွင် user submission နဲ့ ချိတ်ဆက်မှုမရှိလျှင်သာ အသုံးဝင်သည်။ Already published? ကိုဖွင့်ပါ။ Dropdown မှ အမှန်တကယ်တူညီသောပွဲကိုရွေးပြီး Link existing event နှိပ်ပါ။ ပွဲမရွေးရသေးလျှင် ခလုတ်ကို ပိတ်ထားသည်။ ပွဲစာရင်းဗလာဖြစ်လျှင် ချိတ်ရန်ပွဲမရှိသေးပါ။ ချိတ်ခြင်းက event အသစ်မဖန်တီးဘဲ user status ကို လက်ရှိပွဲနှင့်ဆက်ပေးသည်။

Import a suggestion file ဆိုတာ

TDSA suggestion JSON ဖိုင်အဟောင်းကို draft အဖြစ်သွင်းရန်သာ ဖြစ်သည်။ Photo/PDF ဖိုင်တင်ရန် မဟုတ်ပါ။ ပုံမှန်အသုံးပြုရာတွင် Inbox မှ Review ကိုနှိပ်ရုံဖြင့် လုံလောက်သည်။ New profile ကို ကိုယ်တိုင်ဖြည့်နိုင်သည်။

၅။ User status များ

  • Waiting for review — admin မစစ်ရသေးပါ။
  • Reviewed — စစ်ပြီးသော်လည်း publication မချိတ်ထားသေးပါ။
  • Published — ချိတ်ထားသောပွဲကို public မြင်နိုင်သည်။
  • Removed or unpublished — ချိတ်ထားသောပွဲ ဖျက်ထားခြင်း သို့မဟုတ် draft/archived ဖြစ်နေခြင်း။

၆။ Access denied ဖြစ်လျှင်

Form ကိုမပိတ်ပါနှင့်။ အောင်မြင်ကြောင်းစာမပေါ်လျှင် ထပ်တလဲလဲ Publish မနှိပ်ပါနှင့်။ ခွင့်ပြုထားသော admin account ဖြစ်ကြောင်း စစ်ပါ။ ဒီ package ၏ rules နှင့် indexes ကို tmf-mm project တွင် Hosting နှင့်အတူ deploy လုပ်ထားရန် လိုသည်။ Login ထပ်လုပ်ရုံဖြင့် rules မကိုက်ညီမှုကို မဖြေရှင်းနိုင်ပါ။

firebase deploy --only hosting,firestore:rules,firestore:indexes --project tmf-mm

ဆက်ဖြစ်နေပါက ပွဲခေါင်းစဉ်၊ error စာ၊ အချိန်နှင့် အသုံးပြုထားသော version ကို မှတ်သားပါ။ Google password မပို့ပါနှင့်။

၇။ Community profiles နှင့် Privacy

မူရင်းစာရင်းထဲက ကျောင်း/စေတီ/အဖွဲ့အစည်းကို ပြင်ရန် Community profiles → Edit directory place ကိုနှိပ်ပါ။ အမည်ရှာပြီး ရွေးပါ။ လိပ်စာ၊ ဖုန်း၊ Public email၊ Website နှင့် photo ကိုဖြည့်ပြင်ပြီး Publish နှိပ်ပါ။ နောက်ပိုင်း Edit / Publish မှ ပြန်ပြင်နိုင်သည်။ မူရင်းစာရင်းကို ထပ်မပွားဘဲ ပြင်ထားသော profile ဖြင့် အစားထိုးပြသည်။

Community profiles တွင်လည်း တူညီသော workflow ဖြင့် ကျောင်း/အဖွဲ့အစည်း profile တင်နိုင်သည်။ Privacy / removal requests ကို public draft အဖြစ် မသုံးပါနှင့်။ လိုအပ်သည့်ကိစ္စကို ဖြေရှင်းပြီးမှ Mark reviewed လုပ်ပါ။

၈။ Reaction နှင့် connection

Reaction နှိပ်လျှင် ရွေးချယ်မှုနှင့် ဂဏန်းကို ချက်ချင်းပြသည်။ Server က ငြင်းပယ်လျှင် ပြန်ပြောင်းပြီး error ပြသည်။ Google account တစ်ခုက ❤️ 🙏 🎉 တစ်ခုစီကို တစ်ကြိမ်စီ ပေးနိုင်သည်။ ပေးပြီးသားကို ထပ်ပေးခြင်း၊ ပြန်ဖြုတ်ခြင်း မရပါ။ အခြားသူများ၏ reaction များလည်း အလိုအလျောက် ပြောင်းပြသည်။ Network ပြတ်လျှင် live update နောက်ကျနိုင်သည်။

နေရာအတွက် ပုံ ၅ ပုံ ထည့်ရန်

Admin → Place profiles → Edit / Publish (သို့) Edit directory place → Add photos မှ ပုံ ၅ ပုံအထိ ရွေးပါ။ ပုံများကို အလိုအလျောက် ချုံ့ပေးပါသည်။ Move left / Move right ဖြင့် စီစဉ်ပြီး Remove ဖြင့် ဖယ်နိုင်သည်။ Save profile / Publish နှိပ်မှ ပြောင်းလဲမှုများ သိမ်းပါသည်။

စာရင်းကဒ်တွင် icon ကို ဆက်ပြပြီး modal ဖွင့်မှ ပုံကို ဖတ်ယူသည်။ ဖုန်းတွင် ဘယ်ညာဆွဲကြည့်နိုင်သည်။ ပုံမရှိလျှင် မထည့်ဘဲ ထားနိုင်သည်။ ကိုယ်ပိုင် သို့မဟုတ် အသုံးပြုခွင့်ရသော ပုံများသာ တင်ပါ။
